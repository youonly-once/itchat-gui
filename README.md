# 已解决“您的微信不支持登录网页版微信的”问题。
# Java Swing实现网页版微信桌面端增强版。
在保证基本的微信功能外利用微信网页版API+Java Swing做成了桌面端并做了功能增强：聊天记录统计分析、好友属性监测、防撤回、自动回复、定时消息等等。
